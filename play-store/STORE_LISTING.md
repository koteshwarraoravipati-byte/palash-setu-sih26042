# Google Play Store listing draft

## App name

PALASH Setu

## Short description

Offline Hindi-to-Santhali classroom support for foundational learning.

## Full description

PALASH Setu is an offline-first classroom companion for teachers working in mother-tongue-based primary education settings.

The Santhali-first prototype helps a Hindi-medium teacher:

- open short FLN-aligned lesson cards;
- use classroom phrase prompts;
- try optional Hindi voice input on supported Android devices;
- view bilingual worksheet and visual-aid concepts;
- continue using core content without a live internet connection after content synchronisation.

The app is designed for low-cost Android 9+ tablets and follows a safety-first content workflow. Santhali translations and audio are shown as approved only after review by a Santhali-speaking language expert. Unreviewed content is clearly marked for review and is not presented as authoritative.

PALASH Setu is an SIH26042 prototype by Team Sprit. Ho and Mundari are planned expansion languages and are not claimed as supported in this first release.
