# Santhali dataset workflow

This dataset is an education safety boundary, not just training data. Do not fill target-language fields from an unverified online translation.

## Required fields

- Hindi source
- Target-language text in the agreed script
- Transliteration for the teacher
- Meaning-preservation review
- Naturalness review
- Grade and learning outcome
- Native reviewer name/role
- Audio filename and recording quality
- Approval date and content-pack version

## Collection process

1. Draft the Hindi classroom phrase with a primary teacher.
2. Ask a Santhali-speaking teacher/expert to translate naturally for children.
3. Back-translate to Hindi with a second reviewer where possible.
4. Record a quiet, slow, child-friendly version.
5. Review written form, pronunciation and classroom suitability.
6. Mark approved only when the reviewer signs off.
7. Pilot a small lesson with a teacher before expanding.
