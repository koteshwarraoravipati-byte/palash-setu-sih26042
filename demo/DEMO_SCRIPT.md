# PALASH Setu internal demo script

## Before recording

- Install the app on an Android 9+ device.
- Load native-reviewed Santhali phrases and recordings before claiming translation/audio accuracy.
- Turn on airplane mode.
- Prepare a Santhali-speaking reviewer to confirm the output.

## Three-minute flow

1. Problem: Hindi-medium teachers need a bridge to deliver FLN instruction in the child’s home language.
2. Show airplane mode and open PALASH Setu.
3. Select Grade 1 Mathematics and Counting Objects.
4. Show the Hindi script, Santhali output, transliteration and review status.
5. Use the offline speech adapter or phrase button and play the approved recording.
6. Open a visual flashcard.
7. Generate the bilingual worksheet preview.
8. Show the outcome mapping, pack version and safe fallback for unapproved phrases.
9. Close with Santhali-first scope and the reviewed expansion path to Ho and Mundari.

## Claims to show only after testing

- Measured response latency on the target tablet
- Number of approved phrases
- Offline memory footprint
- Native reviewer acceptance
